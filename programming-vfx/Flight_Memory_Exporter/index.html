Flight Memory Exporter

View on GitHub

Overview

Flight Memory Exporter is a tool I built to pull your logged flight history from FlightMemory.com and save it as a ready-to-use .xlsx file.

Since FlightMemory.com doesn't offer a public API, the tool relies on web scraping to pull the data straight from the site. It was originally meant to produce a file importable into MyFlightradar24, but the airport IDs that format requires aren't exposed on FlightMemory.com — so the export is best suited for personal record-keeping rather than re-importing elsewhere.

Code construction

The tool is built around a few key libraries:

  • Selenium — drives Chrome browser to log in and page through the flight history
  • chromedriver-autoinstaller — installs and manages the matching ChromeDriver automatically
  • BeautifulSoup4 — parses the saved HTML pages to pull flight data out of the table
  • Openpyxl — writes the parsed data into an Excel workbook
  • Tkinter — provides the simple desktop GUI

Once logged in, the tool navigates to the flight data page and saves every page of results, clicking the "next" button until it disappears — which signals that the last page has been reached.


while True:
        try:
            WebDriverWait(driver, 10).until(
                expected_conditions.element_to_be_clickable((By.XPATH, "//img[contains(@src,'/images/next.gif')]"))).click()
            pages.append(driver.execute_script("return document.documentElement.outerHTML"))
        except TimeoutException:
            print(f"Pages Found:{int(len(pages))}")
            break
